# Social Media Design

Design for thumb-speed attention and platform-native behavior.

## Principles
- **Stop the scroll in under 1 second:** one focal element, high contrast, minimal text.
- **Design for the feed grid and the single post.** Check both.
- **Mobile first:** test at actual phone size; body text at least 24 px on a 1080 px canvas.
- **Consistency over variety:** recurring templates, color blocks and type lock-ups build recognition.
- **Native over polished:** adapt to platform conventions, captions, sound-off video.

## Formats (verify current specs before delivery)
| Format               | Ratio / size          | Notes                                   |
|----------------------|-----------------------|-----------------------------------------|
| Square / portrait post | 1:1, 4:5 (1080x1350)| 4:5 takes the most feed space           |
| Story / Reel / Short | 9:16 (1080x1920)      | Keep key content out of top/bottom ~250 px UI zones |
| Carousel             | 1:1 or 4:5, 2-10 slides| Slide 1 = hook, last slide = CTA        |
| Cover/profile        | Platform specific     | Avatar crops circular; keep mark centered|

## Carousel structure
1. Hook (promise or question)
2. Context / problem
3. 3-6 value slides, one idea each, consistent layout
4. Summary or takeaway
5. CTA (save, share, follow, link)

## Content system
- Define 3-5 **content pillars** and a template per pillar.
- Build a reusable kit: color-coded backgrounds, type styles, icon set, frame/sticker assets.
- Keep text short: headline 6-10 words, one supporting line.
- Always provide caption direction, alt text and hashtag/keyword guidance.

## Accessibility
Contrast 4.5:1, captions on video, alt text, avoid text-only-in-image for essential info.
