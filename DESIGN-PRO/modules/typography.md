# Typography

Type carries voice and structure. Choose with purpose, then set it carefully.

## Selection
- Match the typeface's personality to the brand traits, then test at real sizes.
- Limit to **two families** (one can be a superfamily with many weights).
- Check language support, weights, numerals (tabular vs proportional), licensing (print, web, app, embed).
- Pair by contrast: serif + sans, geometric + humanist, display + neutral text.

## Hierarchy
Define a scale (e.g. 1.25 major third): 12 / 15 / 19 / 24 / 30 / 38 / 48. Use weight, size, color and space, not all at once.

## Setting rules
| Property      | Body text guideline                     |
|---------------|-----------------------------------------|
| Size          | 16-18 px screen, 9-11 pt print          |
| Line height   | 1.4-1.6 body, 1.0-1.2 large display     |
| Measure       | 45-75 characters per line               |
| Tracking      | Slightly open for small caps/all caps and tiny text; slightly tight for large display |
| Alignment     | Left-aligned for reading; avoid justified without hyphenation |

## Details that signal craft
- Real quotes and apostrophes, en/em dashes, proper ellipsis.
- Optical alignment of hanging punctuation.
- Avoid widows/orphans and awkward rag; fix line breaks manually in headlines.
- Never fake bold/italic; use true styles.
- Don't stretch, outline thin fonts, or set long text in all caps.
