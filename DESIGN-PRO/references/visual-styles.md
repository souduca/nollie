# Visual Styles

Vocabulary for art direction. Use to name a direction, then adapt it to the brief rather than copying it.

| Style              | Traits                                                         | Fits                       |
|--------------------|----------------------------------------------------------------|----------------------------|
| Minimalism         | Few elements, generous space, restrained palette               | Premium, tech, wellness    |
| Swiss / International | Grid, sans-serif, objective photography, asymmetry          | Corporate, cultural, editorial |
| Brutalism          | Raw, heavy type, stark contrast, system fonts, visible structure | Fashion, art, disruptors |
| Neo-brutalism (UI) | Thick outlines, hard shadows, flat saturated color             | Startups, playful products |
| Modernism / Bauhaus| Geometry, primary colors, function-led                         | Education, architecture    |
| Art Deco           | Symmetry, gold accents, geometric ornament                     | Luxury, hospitality        |
| Mid-century        | Organic shapes, muted warm palette, simple illustration        | Lifestyle, heritage        |
| Retro / Y2K        | Gradients, chrome, pixel or techno motifs                      | Nostalgia, youth culture   |
| Maximalism         | Layered, saturated, pattern-rich                               | Entertainment, fashion     |
| Editorial          | Expressive serif, big imagery, dramatic scale                  | Media, culture             |
| Glassmorphism      | Blur, translucency, light borders                              | UI accents (use sparingly) |
| Flat / Material    | Simple shapes, clear elevation, bold color                     | Apps, product UI           |
| Organic / Natural  | Earth tones, texture, hand-drawn lines                         | Food, sustainability       |
| Futurist / Tech    | Dark mode, gradients, mono type, data motifs                   | AI, SaaS, gaming           |
| Hand-crafted       | Illustration, lettering, imperfection                          | Community, craft, kids     |

## Mixing styles
Pick one **dominant** style and one **accent** influence. Keep type, color and imagery consistent with that decision.

## Avoiding clichés
Check category defaults (blue for finance, leaves for eco) and ask what a distinctive but credible alternative would be.
