# Branding Workflow

## Phase 1: Discovery
- [ ] Brief: business, goals, audience, competitors, constraints, timeline
- [ ] Competitive audit: map visuals and tone; find the open space
- [ ] Stakeholder questions: values, fears, "never" list
**Output:** discovery summary + assumptions

## Phase 2: Strategy
- [ ] Purpose, positioning, personality, voice
- [ ] Brand idea in one sentence
- [ ] Keywords / territories (2-3 options)
**Output:** brand strategy one-pager; get alignment before design

## Phase 3: Concept
- [ ] 2-3 distinct directions, each with name, rationale, moodboard
- [ ] Sketch logo routes, then type and color per direction
- [ ] Stress-test: small size, one color, dark/light, in application
**Output:** direction presentation with a recommendation

## Phase 4: Development
- [ ] Refine chosen direction (kerning, geometry, optical balance)
- [ ] Build palette, type system, imagery rules, graphic devices
- [ ] Create logo variants and clear-space/min-size rules
- [ ] Mock up key applications (digital, print, social, packaging)

## Phase 5: Guidelines and delivery
- [ ] Brand guidelines (strategy, logo, color, type, imagery, voice, do/don't)
- [ ] Export asset pack (SVG, PDF, PNG; RGB/CMYK; light/dark)
- [ ] Templates (social, presentation, docs)
- [ ] Rollout plan and ownership

## Gate
Run `creative-review.md` at the end of Phases 3 and 5.
