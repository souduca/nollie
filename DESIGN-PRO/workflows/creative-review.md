# Creative Review

Run before presenting any design output, and when critiquing existing work.

## 1. Brief fit
- Does it solve the stated goal for the stated audience?
- Can the core idea be said in one sentence?

## 2. Scorecard (1-5 each; fix anything at 2 or lower)
| Area            | Questions                                              |
|-----------------|--------------------------------------------------------|
| Concept         | Original, relevant, ownable?                           |
| Hierarchy       | Is the reading order clear in a 3-second squint test?  |
| Composition     | Grid, alignment, spacing, balance                      |
| Typography      | Legible, limited families, consistent styles           |
| Color           | Purposeful palette, contrast >= 4.5:1 for text         |
| Imagery         | Quality, consistency, supports message                 |
| Consistency     | Follows the system and brand rules                     |
| Craft           | Details: kerning, edges, resolution, export            |
| Accessibility   | Contrast, size, motion, alt text/captions              |
| Feasibility     | Production, platform and technical constraints         |

## 3. Quick tests
- Squint / blur test
- Thumbnail test
- Grayscale test
- Competitor lineup test
- Fresh-eyes test (read it as a stranger)

## 4. Feedback format
For every issue: **Observation**, **Why it matters**, **Fix**. Order by impact; start with what works.

## 5. Decision
- **Ship** if no area is below 3 and the concept is clear.
- **Revise** with a prioritized fix list.
- **Rethink** if the concept fails the brief.

## 6. Handoff summary
List final specs (fonts, colors, sizes), assets delivered, assumptions made, and recommended next steps.
