# Social Media Workflow

## 1. Goal and audience
- [ ] Objective (awareness, engagement, conversion, community) and KPI
- [ ] Platforms and audience behavior on each
- [ ] Brand assets and voice available (pull from branding output if it exists)

## 2. Content strategy
- [ ] 3-5 content pillars
- [ ] Formats per pillar (static, carousel, short video, story)
- [ ] Cadence and calendar skeleton

## 3. Visual system
- [ ] Templates per format and pillar (grid and safe zones marked)
- [ ] Type styles, color blocks, icon/sticker kit
- [ ] Photo/illustration treatment rules

## 4. Production
- [ ] Write hook-first copy (headline, support line, CTA)
- [ ] Design in the correct ratio and safe zones
- [ ] Add captions/subtitles, alt text
- [ ] Export at platform specs (verify current requirements)

## 5. QA checklist
- [ ] Legible on a phone at arm's length
- [ ] Focal point identifiable in 1 second
- [ ] Contrast and caption accessibility
- [ ] Brand consistency in feed view (9-post preview)
- [ ] Links, handles, hashtags and legal text correct

## 6. Publish and learn
- [ ] Schedule or hand off with caption direction
- [ ] Review metrics at 24 h and 7 days
- [ ] Keep, change or kill each template; document learnings

Finish with `creative-review.md`.
